# 自媒体助手 · Lovart 提示词（移动端 App）

给 Lovart 出移动端设计图用。能力以产品规划为准；**下列功能不可删减**。

用法：先发「0. 设计系统」，后面每条开头可加：`遵循「自媒体助手」移动端设计系统；iPhone 15 Pro；中文；功能不可删。`

建议底部 Tab：**今天｜创作｜口播｜灵感｜我的**

---

## 0. 移动端设计系统

```
为「自媒体助手」设计 iOS/Android App UI（以 iPhone 15 Pro 390×844 为主画板，另出一套 Android 参考）。这是创作者工具的移动端：采灵感、练口播、读稿小改、发前打包、回填数据、被推送拉回来做事。桌面端负责重编辑；手机端强调单手、推送、相机、麦克风、分享扩展、离线。

硬性要求：
- 功能清单不可删减，只做移动端信息架构与视觉
- 中文 UI；底部 Tab + 顶栏账号切换为一级导航
- 大触控、安全区、深色提词器模式与日间阅读模式分开
- 避免紫渐变 AI 风、奶油衬线风、过度玻璃拟态
- 状态要设计全：空、加载、离线待同步、失败可重试、推送点进深链
- 输出高保真，关键区域用中文标注名称
```

## 1. App 壳 · 账号一键切换 · 「今天」首页

```
设计「自媒体助手」App 首页「今天」+ 全局壳。

【全局】
- 顶栏左侧：当前账号头像/名称，点开「账号切换器」（列表多账号，一键切换；切换后任务/口播/回填都跟这个号）
- 顶栏右侧：任务入口（角标=进行中口播/出图数）
- 底部 Tab：今天｜创作｜口播｜灵感｜我的

【今天页必须有的模块】
1) 待办条（可点直达，不必进首页再找）：
   - 待填发布数据（第1天/第7天）
   - 进行中的口播评测 / 出图任务
   - 选题池未用灵感条数
2) 今日可发：已成稿、待发布的卡片（进阅读/发布包）
3) 口播未练提醒：有口播提示但还没合格录音的稿
4) 额度提示：剩余点数；将用尽时警告
5) 失败任务：可一键重试
6) 本周日历缩略（连载视角）：已成稿/待口播/已发布/待回填色点，点进内容日历

空状态：新号引导「快速建号」或「记一条灵感」。
风格：清醒日程板，不是社交媒体信息流。
```

## 2. 推送与小组件

```
设计「自媒体助手」推送通知样式 + 桌面/锁屏小组件，同一视觉语言。

【推送文案场景必须覆盖】
- 发布后第1天：回填数据
- 发布后第7天：回填数据 + 可看复盘
- 早上：今天有没有可发的成稿
- 口播未练
- 额度将用尽
- 任务完成（口播评测/出图）可查看
- 任务失败可重试
- 离线内容已同步成功（可选）

每条推送点进对应深链页（回填/任务详情/成稿阅读/口播结果）。

【小组件】
- 中号：待填数据数｜进行中任务｜选题池未用数，三块可点
- 小号：下一步主行动（如「回填《xxx》」）
```

## 3. 口播 · 录前试镜 + 提词录制（前置摄像头）

```
设计口播录制主流程（可 3 帧：试镜｜提词录制｜提交中）。

【录前试镜 10～30 秒】
- 前置摄像头全屏预览
- 实时：构图参考框（人脸居中）、光线提示（过暗/逆光/OK）、音量电平条
- 倒计时可选 10/20/30 秒试镜，不上传
- 「开始提词录制」主按钮
- 预设切换：室外｜车上｜室内（影响字号、滚速、亮度、防息屏默认）

【提词录制（App 核心差异：网页只能录音，App 录视频+提词）】
- 上半或画中画：前置摄像头自拍预览
- 主区域：大号提词滚动正文；分段语气/动作提示可开关
- 防息屏开启标识
- 控件：播放/暂停滚动｜速度｜字号｜镜像｜提示开闭｜重来｜结束并上传
- 录制红点与时长
- 结束 →「交给任务队列评测」确认；显示已入队，可去任务中心

须体现：滚动提词与录像同时进行；网络差时可先本地保存再入队。
```

## 4. 口播评测结果 · 通知后回看 · 重拍

```
设计「口播评测结果」页（从推送或任务中心进入）。

必须包含：
- 总分 + 分项（完整/发音/节奏/表达/出镜等，未测项显示未测而非 0）
- 录像或音频回放
- 句子/段落列表：每条分数或标记；点某一句 → 提词/原稿定位滚动到该句并高亮
- 「重拍这一遍」（回到提词录制，可带同一稿）
- 「只重测发音/出镜」类次要入口（若产品有按维重测）
- 状态：评测中骨架屏｜完成｜失败重试

顶部可有推送到达暗示：「评测好了，马上能看」。
单手可操作，重点是点句跳转与重拍。
```

## 5. 灵感 Tab · 随手记 + 分享入库 + 离线

```
设计「灵感」Tab 主页 + 录入态 + 分享扩展（可拼图）。

【灵感首页】
- 大入口三键：语音记｜打字记｜拍照记
- 「从剪贴板导入」
- 列表：待同步（云图标灰）/已同步；每条显示类型（语音/文字/图）、预览、目标（选题池/素材库）
- 筛选：全部｜选题池｜素材库｜未同步

【录入表单】
- 内容区（转写文本可改 / 照片预览 / 链接预览）
- 存到：选题池｜素材库（素材可选种类、标题、标签）
- 关联当前账号
- 保存；无网时文案「已存本地，联网后自动上传」

【系统分享扩展 UI】
- 从微信/浏览器分享文章、截图、链接、别人的文案到「自媒体助手」
- 选择：进选题池 / 进素材库；可改标题；选账号
- 成功反馈

强调地铁场景：离线可记，有网再交。
```

## 6. 对标账号速存

```
设计「对标速存」轻量页（入口可在灵感 Tab「···」或素材库）。

- 粘贴主页或笔记链接
- 「拉取可引用信息」（只抽标题/结构要点进「我的对标」，不是完整爬虫产品）
- 结果卡：标题、结构大纲/要点、来源链接
- 操作：存进素材库｜存为框架参考（说明：只作参考，不抄内容）
- 历史「我存过的对标」列表

文案避免承诺「全网监控」；强调「我存下来的对标」。
```

## 7. 创作 · 快速出稿（题材→方向→成稿阅读）

```
设计移动端「创作」主路径，三步，手机以阅读和小改为主。

Step1 选题：题材输入；可选栏目；写法框架精简选择；借势热点条；从选题池选用；主按钮「出三个方向」
Step2 方向：三个方向卡（标签、标题、差异、结构摘要）「用这个写」
Step3 成稿阅读态（默认）：
- 标题、字数、平台
- 正文大字阅读
- 底栏主操作：改一点｜语音改｜发布包｜更多
- 更多菜单：标题候选｜配图（保存到相册）｜口播｜回填数据｜喂给语气样本｜归档｜任务

编辑是次要：不要做成桌面那种重型编辑器；小改=选段+语音/短指令。
```

## 8. 发布包（按平台一键/分步复制）

```
设计「发布包」全屏页（成稿完成后进入）。

- 平台分段（公众号/小红书/视频号等，按该稿版本）
- 每一块包含：标题、正文、话题标签、配图说明（可多图）
- 字数检测：超限红字提示；符合则通过
- 操作：一次复制全部｜分步复制（标题/正文/标签/配图说明）
- 「配图保存到相册」（批量或逐张）
- 复制成功 Toast

目标：改完就能去各 App 粘贴发布。干净、清单式。
```

## 9. 标题候选（移动）

```
设计标题候选半屏/全屏：平台字数上限说明；约 6 条候选；字数与超限/风险标记；点选替换标题；「换一批」。
选出后可「写入发布包」。大点击热区。
```

## 10. 语音改稿 + 审稿左右滑

```
两帧同属「通勤改稿」：

A. 语音改稿：
- 选中段高亮或「整篇」
- 按住说话：「这段改短点」「语气活泼些」
- 转写预览 → 生成改写对比（原文/新文）→ 采用｜重说｜取消

B. 内容质量/违禁/改写建议卡堆：
- 一张建议一张卡（问题引用句、说明、风险级）
- 左右滑：接受｜跳过｜稍后（稍后进「今天」待办）
- 底部可撤销

单手持机横滑，地铁场景。
```

## 11. 任务中心（移动）

```
设计「任务」页（顶栏入口）。

分组：进行中｜已完成｜失败
类型：出图、口播文字总评、发音/出镜评测…
卡片：标题、账号、状态、进度、错误原因
操作：取消（排队）｜重试｜查看结果（出图可存相册；口播进评测页）
空状态说明后台继续跑、关掉 App 也会做。

与桌面任务中心能力对齐，布局更适合拇指列表。
```

## 12. 发布数据回填 + 只读复盘

```
A. 回填页（推送第1/7天直达）：
- 稿件标题、发布日、今天是第几天
- 指标输入、备注、多平台切换
- 历次回填简表
- 保存；「看复盘」

B. 复盘只读页：
- 样本不足时的诚实空态
- 有数据时：方向/框架效果摘要、列表只读
- 无复杂筛选，适合手机快速瞄一眼
```

## 13. 内容日历（只读 + 轻改状态）

```
设计「内容日历」周视图（连载型账号）。

- 周切换
- 每天格子/列表：稿件标题 + 状态色点
  状态枚举必须有：已成稿｜待口播｜已发布｜待回填（可并存提示）
- 点条目 → 成稿阅读 / 口播 / 回填（按状态给主 CTA）
- 允许轻改状态（如标已发布），不要做成重排期甘特图
- 说明：灵感型账号可忽略此页

入口：今天页日历缩略、「我的」内。
```

## 14. 快速建号 + 发布后喂样本（同一能力链）

```
设计两条紧密相关的界面：

A. 快速建号：
- 贴自我介绍（语音转写或打字）
- 可选贴旧文章（多篇分隔）
- 「帮我填好账号设定」→ 结果预览可改 → 保存
- 也可「自己一项项填」精简表单（名称、平台、定位、用户、问题）

B. 发布后「喂给语气」：
- 分享/粘贴刚发的爆款或满意旧文
- 加入语气样本列表
- 触发「重建语气档案」进度
- 完成反馈：以后成稿会更像你

强调：建号与养成在同一条链，适合发完立刻在手机做。
```

## 15. 「我的」页

```
设计「我的」Tab：
- 当前账号卡（切换账号）
- 用量与套餐入口（剩余点数）
- 内容日历
- 对标速存
- 语气样本/素材库入口
- 说明书/帮助
- 退出登录
- 设置：提词器默认预设、防息屏、通知开关（分组：回填/早间/口播/任务/额度）

不要塞桌面端管理后台。
```

## 16. 配图结果 · 存相册

```
设计成稿配图列表移动态：每张缩略图、画面说明、状态（生成中/完成/失败）；
操作：保存到相册｜重试；顶栏「全部保存到相册」。
权限被拒时的引导态要画出来。
```
