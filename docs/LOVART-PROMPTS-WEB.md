# 自媒体助手 · Lovart 提示词（Web / 桌面端）

给 Lovart 出设计图用。功能与现网一致，只换视觉与排版；**不得删减功能入口**。

用法：先发「0. 设计系统」，后面每条开头可加一句：`遵循已定的「自媒体助手」设计系统`。

---

## 0. 总控 · 设计系统

```
为 SaaS 产品「自媒体助手」做 Web 端 UI 重设计。功能与信息架构完全不变，只换视觉与排版；不要删减任何功能入口。

产品定位：给自媒体创作者用的中文创作工具——账号语境 + 真实素材 + 选题方向 + 成稿 + 多平台适配 + 配图 + 口播提词/评测 + 发布数据复盘。

设计要求：
- 桌面端优先，宽度 1440px 主画板；干净、专业、可读，适合长时间写作
- 中文界面；中英混排时中文为主
- 避免：紫渐变 AI 风、奶油衬线 Terracotta 风、报纸密排风、过度霓虹/玻璃拟态
- 清晰层级：顶栏 / 左侧栏 / 主工作区 / 模态层
- 主色克制，强调色只用于主 CTA；危险操作用红色 ghost
- 组件：按钮（主/次/ghost/危险）、芯片、卡片、表格、空状态、骨架屏、Toast、下拉菜单、弹层
- 输出：完整页面高保真，标注关键区域名称（中文）
```

## 1. 登录 / 注册 / 访问门禁

```
设计「自媒体助手」登录页高保真。品牌名「自媒体助手」要作为页面主视觉，不是小小导航字。

必须包含两种状态（可出 2 张或一张分栏）：
A. 正常登录/注册：
- 副文案：给一个题材，先出三个话题方向，选中后生成完整成稿
- Tab：登录 / 注册（注册可因配置隐藏）
- 用户名、密码；注册时可选「邀请码」
- 主按钮：登录 / 注册并进入
- 提示：每个账号的创作记录相互独立 / 或不开放公开注册
B. 访问密码门禁态：
- 只显示访问密码输入 +「进入」
- 说明：与 API 网关管理台同一组密码

不要加无关营销模块。浅色或中性背景，大气、可信。
```

## 2. 应用壳 · 顶栏 + 侧栏

```
设计「自媒体助手」登录后主界面骨架（创作视图）：顶栏 + 左侧栏 + 右侧大工作区（工作区可放占位）。

【顶栏必须有】
- 品牌「自媒体助手」
- 导航 Tab：创作 | 热点（创作为当前）
- 右侧：模型通道状态芯片（含演示/在线提示）｜任务按钮（角标显示进行中数量）｜用量芯片（套餐名 · 剩余点数，可点开）｜用户名｜说明书链接｜退出

【左侧栏必须有】
上半「账号设定」：
- 「＋ 新账号」
- 账号列表（头像/名称/定位一行一个；当前账号可展开完整设定摘要）
- 「展开完整设定」
下半「创作记录」：
- 「＋ 新建」
- 筛选：进行中(计数) | 已归档(计数) | 口播(计数)
- 列表项：标题/题材、平台、状态；操作：归档/恢复、删除；当前篇高亮
- 口播模式时切换为口播记录列表容器
- 底栏：「把 N 篇已完成的收起来」

右侧主区留白写「步骤工作区」。整体像专业创作台，不是仪表盘堆卡片。
```

## 3. 创作 · 步骤 1 确定选题（创作简报）

```
在上一屏骨架内，设计「创作」视图步骤 1：确定选题。顶部步骤条：1 确定选题（当前）→ 2 选择话题方向 → 3 创作内容；步骤可回点。

主卡片「创作简报」必须包含：
- 题材多行输入（必填）
- 内容栏目：芯片「常规创作」+ 各栏目芯片（可带篇数）+「管理栏目」
- 选中栏目后：动态素材字段区（标签、必填星号、说明、多行输入）——文案提示「模型只会用你填的，不会自己编」
- 写法框架：推荐三个可点选 + 入口「打开框架库」；可显示「不套框架」
- 若借势热点：热点引用条（标签🔥、标题链接、概要或「没抓到概要」提示、清除）
- 选题池：展开/收起；列表（来源、题材、排期日期、写这条、删）；底部「想到什么先记一条」输入+存入；空状态说明
- 推荐题材：标题「推荐题材」+「换一批」；卡片可点击选用，＋ 存进选题池；可区分热点优先
- 平台 / 风格调性 / 目标字数；可「恢复账号设定」；已锁定时显示继承事实 +「修改」
- 主按钮「生成三个话题方向」+ 旁注提示

若无账号：另出一张引导卡——「先给这个号定个位」；按钮：贴一段自我介绍帮我填｜自己一项项填｜先不设定直接创作。
```

## 4. 创作 · 步骤 2 三个话题方向

```
设计步骤 2「选择话题方向」高保真。步骤条第 2 步高亮。

卡片标题「三个话题方向」，可显示「写法：xxx」副标题；右上「换一批」。

三个方向卡片，每张必须能展示：
- 序号 + 类型标签（如反常识/行业视角）
- 标题
- 「差异」说明（相对另两个方向）
- 「结构」要点列表
- 主按钮：「用这个方向写」或「重新生成这篇」（已选中态）

选中卡片有强调边框。不要改成超过三个方向。
```

## 5. 创作 · 步骤 3 成稿工作台

```
设计步骤 3「创作内容」成稿工作台，功能极多但必须全部保留入口。

【标题吸顶区】
- 「← 换方向」｜标题「完整文案」｜字数计数｜当前模式指示（阅读/编辑）

【工具条三组】
1) 「← 返回阅读」「修改」「版本」
2) 「确认 ▾」下拉菜单，菜单项必须齐全：
   - 生成口播提示（切段、标语气，配合提词器）
   - 起标题（6 个候选）
   - 出多平台版本（事实不变，按平台重排）
   - 配图（正文可插「此处放图片」；或自动排位；需「全部出图」）
   - 喂给账号学习（语气样本）
   - 再检查一遍（错字、通顺、调性与风险）
   - 回填发布数据
   - 归档
3) 「导出 ▾」：复制（含图富文本）｜Markdown｜图文 HTML｜Word｜PDF（打印另存）
- 旁注 toolHint；编辑态显示保存状态 +「保存」

【正文区状态（可分镜）】
A 阅读态：Markdown 渲染正文；可内嵌配图
B 编辑态：大文本编辑器；底栏提示「选中文字→AI改写 · 输入/ →续写」；「此处放图片」可拖拽标签 +「语音改稿」+ 语音结果备注

【可展开面板，需在设计里体现入口或展开态】
- 版本对照：历史列表 + 左旧右当前 diff 式对照
- 检查结果：总评、风险、摘要、「全部采纳」、问题列表与旗帜
- 多平台：平台多选 +「生成选中的版本」+ 版本 Tab
- 配图条：状态芯片、提示、「重新排版位」「全部出图」、图位列表（提示词/出图/重试）
- 口播区：总体指标；「提词器」「复制口播稿」「生成口播提示」；分句提示列表；口播记录（上传音视频、列表、文字总评；语音测评/视频测评按条触发）

视觉重点是长文可读 + 工具不抢正文。
```

## 6. 编辑浮层 · 划词改写 / 斜杠续写 / 助手结果

```
为「自媒体助手」成稿编辑器设计三组浮层（可一张拼图）：

1) 划词菜单（选中文字后）：扩写｜专业点｜轻松点｜缩写｜举个例子｜更好懂
2) 斜杠菜单「/」：续写这一段｜加个小标题｜写个结尾｜写个开头；底部自由输入「或直接说要写什么，回车确认」
3) 助手结果气泡：流式输出区、采用/重试/关闭类操作（保持轻量）

背景是模糊的正文选区。中文 UI，桌面端。
```

## 7. 提词器全屏

```
设计「自媒体助手」口播提词器全屏页。

顶栏控件必须有：
▶ 开始（空格）｜● 录（录完去总评）｜滚动速度｜字号｜提示 开/关｜镜像｜⟲ 重来｜进度 %｜✕ 退出

主舞台：大号提词正文垂直滚动；可显示分段语气/动作提示；可镜像。
氛围适合拍摄：深色背景、高对比文字、防息屏感（勿花哨动画）。
```

## 8. 热点视图

```
设计顶栏切到「热点」后的整页（侧栏仍在）。

上卡「可蹭的热点」：
- 「抓取并比对」主按钮 + 更新时间
- 说明：与当前账号定位比对；核实原文；伤亡/灾难/点名争议不推荐
- 来源状态胶囊（成功/失败 + 条数）
- 匹配结果卡：平台、关联度强弱、热度、原标题链接、原文概要、蹭点、选题建议、注意分寸、「用这个题材去创作」
- 空状态/未选账号提示

下卡「抓到的原始榜单」：
- 平台筛选、重新抓取
- 列表：序号、平台、标题链接、热度
- 折叠「榜单抓不到？手动粘一份」：多行粘贴 +「用这份榜单比对」
```

## 9. 账号设定整页

```
设计「自媒体助手」账号设定全屏页（盖在应用上）。

顶栏：← 返回｜标题新建/编辑账号｜保存提示｜删除账号｜取消｜保存

左侧导航四块（未保存账号时后两块可禁用提示「先保存账号」）：
1) 基本：名称*、发布平台、风格调性、主要内容、目标用户、解决的问题、备注/禁忌；新账号提示「贴一段自我介绍帮你填」
2) 个人人设：年龄、性别、行业、岗位、性格特征
3) 素材库：种类、标题、正文、标签、「存进素材库」；列表（种类、标题、用过次数、改/删、标签）
4) 语气样本：样本列表（标题、字数、删）、学到的语气档案摘要、「重新学习」、从成稿「喂给账号学习」的说明

表单分区清晰，长页可滚动。
```

## 10. 栏目管理弹窗

```
弹窗「内容栏目」，副标题带账号名。

必须包含：
- 已有栏目列表（排序、编辑、删除）
- 从预设下拉添加 +「添加」
- 编辑表单：名称、栏目目的、写作指南、默认写法框架、自定义素材字段（标签/说明/必填，最多多项，可增删）、「保存栏目」「取消」

说明文案：栏目决定每次创作要用户提供哪些真实素材。
```

## 11. 框架库弹窗

```
大弹窗「框架库」——写法结构：每段干什么、各占多少篇幅。

工具条：Tab 全部/内置/我的｜平台筛选｜从范文拆解｜＋ 新建框架

列表卡：名称、内置/我的、适用平台、有范文标记、用过次数、摘要、段落占比条、「用这个写」「复制到我的」或编辑/删除

「从范文拆解」态：大文本、读 txt/md、范文平台、字数、拆解按钮
「编辑」态：框架名、说明、适用平台多选、场景、段落列表（作用/要点/占比%/上下移/删）、占比预览条、保存

不要做成文章编辑器，这是结构模板库。
```

## 13. 任务中心弹窗

```
弹窗「任务」：出图和口播评测在后台做，关掉页面也不会丢。

列表项：类型标签（出图/口播等）、名称、状态（排队/进行中/完成/失败）、错误信息、时间；操作：取消（排队中）、重试（失败）、查看结果。
空状态：还没有任务…
进行中条目有进度感。
```

## 14. 用量与套餐 / 支付

```
宽弹窗「用量与套餐」。

左/上：当前套餐与剩余点数、周期；本月消耗明细表（功能、次数、点数）
右/下：套餐卡片（免费/付费档权益差异，免费档限制配图等）+ 加购点卡
说明：点数按实际消耗；写稿便宜，出图是大头

支付子面板：订单标题、金额、渠道选择（微信/支付宝/演示）、二维码或演示「模拟支付成功」、订单号与等待提示、取消。
```

## 15. 发布数据回填 + 复盘

```
两张相关界面：

A. 弹窗「回填发布数据」：
- 发布日期、本次记录日期；多平台时选平台
- 指标数字输入（阅读/点赞等，占位可显示上次）
- 备注
- 说明：可隔几天再填；同日覆盖；清空保存=删当天
- 历次回填列表（日期、第 N 天、平台、数字摘要、删除）
- 「看复盘 →」「保存」

B. 宽弹窗「复盘」：
- 已回填 N 篇
- 只读洞察：什么框架/方向有效、中位数对比、说明样本不足时不瞎总结
- 表格或卡片列表展示稿件与数据
```

## 17. 营销落地页（可选）

```
重设计「自媒体助手」官网落地页。品牌「自媒体助手」是首屏主视觉。

首屏只保留：品牌、一句主标题、一句副标题、一组 CTA（登录进入 / 先看怎么工作）、一句免费档说明；下方可有产品界面预览（选题方向三选一）。不要把功能列表塞进首屏。

后续区块（可滚动）：
- 通用 AI vs 本产品对比
- 三件差异：账号语境、真实素材不编造、从成稿到口播
- 价格区占位
- 页脚

中文，克制高级，非 AI 紫渐变模板。
```

## 18. 管理后台（可选）

```
设计「自媒体助手 · 管理后台」桌面端。独立登录门（管理员用户名/密码）。

登录后：顶栏（模型芯片、管理员名、退出）+ 左侧导航，右侧内容。导航与页面必须全覆盖：
- 使用概览（天数筛选、刷新、统计卡、趋势）
- 提示词 A/B（功能选择、变体列表、权重、生效、编辑 system）
- Eval（用例、跑一批、批次结果、盲测）
- 内容质量表
- 成本估算表
- 支付接入（字段表单、连通性自检；密钥只写不读）
- 用户表
- 各功能用量 + 错误列表
- 各功能提示词目录
- 管理员账号表

数据密集但清晰，像严谨的内部工具，不是营销站。
```
