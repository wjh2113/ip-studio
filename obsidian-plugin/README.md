# 自媒体助手同步（Obsidian 插件）

- **成稿**：助手 → 知识库（单向增量），每篇一个 `.md`，配图下载嵌入。
- **素材**：助手 ↔ 你指定的素材文件夹（双向）。冲突时两边都留，不自动盖掉。

## 安装（Windows）

1. 打开自媒体助手网页，右上角点「**同步**」：
   - 下载 `main.js`、`manifest.json`、`styles.css` 三个文件（已装过请覆盖到 0.2）；
   - 点「生成同步密钥」，复制那串 `ips_` 开头的密钥（**只显示一次**）。
2. 在资源管理器里打开你的知识库文件夹，进到 `.obsidian\plugins\`，
   新建（或打开）文件夹 `ip-studio-sync`，把三个文件放进去。
3. Obsidian「设置 → 第三方插件」：关掉「安全模式 / 受限模式」，启用「**自媒体助手同步**」。
4. 插件设置里填：
   - **服务器地址**（网页「同步」里可复制）；
   - **同步密钥**；
   - **素材文件夹**（默认 `素材库`，可改成你想要的目录）；
   - 点「**测试**」→「立即同步」。

Mac / Linux / 手机版 Obsidian 一样装。

## 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 服务器地址 | 空 | 自媒体助手的网址 |
| 成稿导出接口 | `/api/export/drafts` | 一般不用改 |
| 素材同步接口 | `/api/export/materials` | 一般不用改 |
| 同步密钥 | 空 | 成稿只读；素材可读可写；不能登录、不扣额度 |
| 同步素材库 | 开 | 关掉就只同步成稿 |
| 自动同步间隔（分钟） | 60 | 0 = 不自动；最短 5 分钟 |
| 打开时先同步一次 | 开 | |
| 成稿文件夹 | `自媒体助手` | |
| 配图文件夹 | `自媒体助手/附件` | `ips-<稿子编号>-<原文件名>` |
| 素材文件夹 | `素材库` | **只同步该目录下的 `.md`**，自行选择路径 |
| 按账号分子文件夹 | 开 | 只影响成稿 |
| 包含其他平台版本 | 开 | 成稿正文后的「其他平台版本」 |

左侧栏刷新、命令「立即同步（成稿 + 素材）」、点底部状态栏，都会马上同步。

## 成稿规则

- 只同步**已成稿**且有正文的；增量 cursor；属性里 `ips_id` 认文件。
- 末尾「## 我的笔记」与 `%% 同步只更新…… %%` 以下不覆盖。
- 网页删掉的成稿，库里不会跟着删；归档的有 `archived: true`。

## 素材规则

- **Pull**：从助手拉变更，写入素材文件夹；属性键是 `ips_material_id`（不要和成稿的 `ips_id` 混用）。
- **Push**：把该文件夹里改过的 / 没有 id 的 `.md` 推回助手（新建或更新）。
- **冲突**（上次同步后两边都改过）：本机内容另存为 `原名 (本机副本).md`（无 id），原文件写成助手版；副本下次推送会在助手里**新建**一条。
- 首版只同步正文文本；`图片：/api/...` 这类行原样保留，不另下二进制附件。

## 安全

- 密钥只能调 `/api/export/*`，登录不了网页、扣不了额度。
- 服务端只存哈希；网页「同步」里可作废。
- 密钥在 `.obsidian/plugins/ip-studio-sync/data.json`，知识库上云盘时注意。

## 开发

`main.js` 不用编译。测试：`node --test tests/obsidian.test.js`。接口见 [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md)。
