# 自媒体助手同步（Obsidian 插件）

把自媒体助手里的**成稿**定期同步到 Obsidian 知识库：每篇一个 `.md` 文件，开头是属性（账号、平台、发布日期、标签……），配图下载到知识库里、嵌在原来的位置。

## 安装（Windows）

1. 打开自媒体助手网页，右上角点「**同步**」：
   - 下载 `main.js`、`manifest.json`、`styles.css` 三个文件；
   - 点「生成同步密钥」，复制那串 `ips_` 开头的密钥（**只显示一次**，丢了就作废再生成一把）。
2. 在资源管理器里打开你的知识库文件夹，进到 `.obsidian\plugins\`（`.obsidian` 是隐藏文件夹：资源管理器「查看 → 显示 → 隐藏的项目」打开），
   新建文件夹 `ip-studio-sync`，把三个文件放进去：
   ```
   你的知识库\.obsidian\plugins\ip-studio-sync\main.js
   你的知识库\.obsidian\plugins\ip-studio-sync\manifest.json
   你的知识库\.obsidian\plugins\ip-studio-sync\styles.css
   ```
3. Obsidian「设置 → 第三方插件」：关掉「安全模式」（新版叫「受限模式」，第一次用第三方插件时要关），在已安装插件里打开「**自媒体助手同步**」。
4. 点它的设置（齿轮）：
   - **服务器地址**：自媒体助手的网址，比如 `https://ip.aidigitcloud.cn`（网页「同步」里有，可以直接复制）；
   - **同步密钥**：粘贴第 1 步复制的密钥；
   - 点「**测试**」，提示「连接成功：账号 xxx」就好了，再点「立即同步」。

Mac / Linux / 手机版 Obsidian 一样装，文件夹位置同上。

## 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 服务器地址 | 空 | 自媒体助手的网址 |
| 导出接口 | `/api/export/drafts` | 一般不用改。可以写路径（接在服务器地址后面），也可以写完整网址（比如走另一个域名或反向代理时） |
| 同步密钥 | 空 | 网页「同步」里生成，只能读成稿 |
| 自动同步间隔（分钟） | 60 | 0 = 不自动同步；最短 5 分钟 |
| 打开 Obsidian 时先同步一次 | 开 | 关着的那段时间改过的成稿，一打开就补上 |
| 成稿文件夹 | `自媒体助手` | |
| 配图文件夹 | `自媒体助手/附件` | 图片文件名是 `ips-<稿子编号>-<原文件名>` |
| 按账号分子文件夹 | 开 | `自媒体助手/小鹿旅行记/2026-10-01 标题.md`；没关联账号的放「未关联账号」 |
| 包含其他平台版本 | 开 | 改写过的平台版本放在正文后面「其他平台版本」下 |

左侧栏的刷新按钮、命令面板「立即同步成稿」、点底部状态栏，都会马上同步一次。

## 同步规则

- **只同步成稿**（已完成、有正文的）。还在选方向、生成中的不同步。
- **增量**：插件记住上次同步到哪，只拿之后改过的。想从头再拉一遍，点「全部重新同步」（已有文件就地更新，不会多出一份）。
- **按编号认文件**：文件属性里的 `ips_id` 是稿子编号。标题改了文件会跟着改名（用 Obsidian 自己的改名，别的笔记里指向它的链接一起改）；你把文件挪到成稿文件夹里的别处，插件也认得，但这篇下次有更新时会被挪回按规则的位置。
- **你的笔记不会被覆盖**：每篇末尾有「## 我的笔记」和一行灰色注释 `%% 同步只更新这一行以上的内容…… %%`。这行以下随便写；这行以上是同步来的，下次成稿有改动时会被替换。**别删这行注释**，删了下次更新会把整篇当成新的重写。
- **网页里删掉的成稿**，知识库里不会跟着删；归档的成稿属性里会多一个 `archived: true`。
- **配图**：下载过的不再下。某张图下载失败，同步会停在那一篇，下次从它开始重试，不会漏。
- **文件名**：「发布日期（没发布用创建日期） 标题」。Windows 不允许的字符（`\ / : * ? " < > |`）和 `# ^ [ ]` 会换成空格，太长截到 80 字。

## 安全

- 同步密钥**只能调导出接口**（读成稿和配图），拿它登录不了网页、改不了内容、也不扣额度。
- 服务端只存密钥的哈希。网页「同步」里能看到每把密钥最后一次同步的时间，不用了就点「作废」，立即失效。
- 密钥存在知识库的 `.obsidian/plugins/ip-studio-sync/data.json` 里。知识库如果放在网盘或 Git 里同步，注意这个文件也会跟着走。

## 开发

`main.js` 是不用编译的 CommonJS（`obsidian` 模块由 Obsidian 提供），改完直接替换文件、在 Obsidian 里关掉再打开插件即可。
`package.json` 只是让仓库里的测试按 CommonJS 读它，安装时不需要。

测试在仓库根目录：`node --test tests/obsidian.test.js`（会起一个演示模式的服务，用内存里的假知识库把插件跑一遍）。
服务端接口见 [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md)「同步到 Obsidian」。
